Deploy with GitHub Pages
1. Create or open your GitHub repository.
2. Upload index.html to the repository root.
3. Optionally upload your resume as resume.pdf and/or resume.docx.
4. Commit the files to the branch you want to publish.
5. Open Settings → Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Choose your deployment branch (for example, main) and folder / (root).
8. Click Save and wait for deployment to complete.
9. Open the URL shown in the Pages settings.
For a user site repository named USERNAME.github.io, the URL is typically:
https://USERNAME.github.io/
For a project repository with another name, the URL is typically:
https://USERNAME.github.io/REPOSITORY/
Customize before publishing
- Confirm the professional summary and project descriptions accurately represent your experience.
- Replace the LinkedIn placeholder in index.html with your real profile URL.
- Confirm the email address is correct.
- Upload the resume file with the filename referenced in the HTML.
- Remove any confidential employer, customer, or internal system information from public content.
